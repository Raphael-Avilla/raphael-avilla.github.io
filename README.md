# Raphael Avilla — Microsoft Cloud & Security

Portfólio técnico e base de conhecimento pública com tutoriais, laboratórios e modelos de projetos no ecossistema Microsoft.

**Site publicado:** https://raphael-avilla.github.io/

## Organização

- `docs/index.md` — página inicial e destaques.
- `docs/sobre.md` — apresentação do portfólio.
- `docs/conhecimento/` — documentação e tutoriais por tecnologia.
- `docs/projetos/` — projetos práticos e modelos de estudos de caso.
- `docs/scripts/` — roteiros e automações.
- `docs/stylesheets/extra.css` — identidade visual responsiva.
- `zensical.toml` — estrutura do site, menus, tema e metadados.
- `.github/workflows/docs.yml` — publicação automática via GitHub Actions.

## Como atualizar

1. Faça alterações nos arquivos Markdown da pasta `docs/` ou no CSS.
2. Registre as mudanças com um commit na branch `main`.
3. Envie as alterações para o GitHub (*Push origin* no GitHub Desktop).
4. Acompanhe a publicação em [GitHub Actions](https://github.com/Raphael-Avilla/raphael-avilla.github.io/actions).

O GitHub Actions instala o Zensical, gera os arquivos HTML e publica automaticamente no GitHub Pages. A documentação do Zensical está disponível em https://zensical.org/.

## Transparência e segurança

Os documentos identificados como **modelo** são estruturas didáticas e não representam implementações concluídas. Quando forem publicados projetos reais ou de laboratório, seus resultados e contexto serão identificados. Não publicar informações sensíveis de usuários, organizações ou tenants.
