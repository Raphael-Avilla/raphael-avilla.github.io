PUBLICAR COM GITHUB DESKTOP
1. Instale e abra https://desktop.github.com/ e entre com a conta Raphael-Avilla.
2. File > Clone repository, escolha 'Raphael-Avilla/raphael-avilla.github.io' e clique Clone.
3. No GitHub Desktop, use Repository > Show in Explorer para localizar a pasta clonada.
4. Extraia este ZIP numa OUTRA pasta temporária. Copie seus arquivos e pastas,
   EXCETO o próprio COMO_PUBLICAR.txt, para dentro da pasta clonada.
   Quando o Windows perguntar, escolha substituir os arquivos existentes.
   Atenção: nunca apague a pasta .git dentro da pasta clonada.
5. Volte ao GitHub Desktop. Confira as alterações na aba Changes.
6. Em Summary, escreva: 'Portfólio V2 - identidade visual completa'.
7. Clique Commit to main e, depois, Push origin.
8. Acompanhe a publicação em
   https://github.com/Raphael-Avilla/raphael-avilla.github.io/actions
9. Acesse https://raphael-avilla.github.io/ e recarregue a página.
