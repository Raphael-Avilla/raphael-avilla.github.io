ATUALIZAÇÃO V3.3: BADGES DE CERTIFICAÇÃO

1. Extraia o ZIP em uma pasta temporária.
2. Abra o GitHub Desktop e selecione Show in Explorer.
3. Copie o conteúdo extraído para a pasta do repositório local, substituindo os arquivos existentes.
4. Confira se a nova pasta docs/assets/certificacoes contém quatro imagens PNG.
5. Faça Commit to main com a mensagem: Adiciona badges aos cartões de certificação.
6. Clique em Push origin.
7. Após a publicação automática, abra https://raphael-avilla.github.io/sobre/

Alterações desta versão:
- Quatro badges de certificação inseridos à direita nos cartões.
- Imagens locais com fundo transparente, extraídas da arte fornecida pelo proprietário.
- Layout ajustado para computador e celular.
- Links para validação no Microsoft Learn preservados.
- A página inicial e as outras seções continuam com a identidade visual anterior.
