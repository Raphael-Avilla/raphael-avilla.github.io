# Scripts e automações

Esta seção reunirá seus projetos de PowerShell e Microsoft Graph.

Para cada script, documente:

- **Finalidade:** qual problema resolve.
- **Pré-requisitos:** módulos, permissões, licenças e autenticação.
- **Execução:** exemplos e parâmetros.
- **Segurança:** privilégios mínimos, impacto e limitações.
- **Validação:** como confirmar o resultado.

Quando tiver scripts prontos, você poderá armazenar o código em repositórios específicos do GitHub e adicionar os links aqui.
