# Base de conhecimento

Aqui ficam **procedimentos técnicos e guias passo a passo** organizados por tecnologia.

O formato recomendado para novos guias é:

1. Objetivo e cenário de uso.
2. Pré-requisitos, licenças e permissões necessárias (verificados na documentação oficial).
3. Passo a passo da configuração.
4. Como testar e validar o resultado.
5. Riscos, limitações e referências.
