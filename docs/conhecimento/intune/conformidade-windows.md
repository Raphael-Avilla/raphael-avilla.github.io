# Políticas de conformidade Windows no Intune: modelo

> **MODELO DIDÁTICO: este conteúdo não descreve uma implementação realizada.** Complete com os dados do seu laboratório.

## Objetivo

Explicar a criação de uma política de conformidade e demonstrar como avaliar os resultados no Microsoft Intune.

## Pré-requisitos

Documente os requisitos de licenciamento, as permissões, o método de gerenciamento e os dispositivos de teste utilizados.

## Planejamento

- Público-alvo da política.
- Requisitos de conformidade escolhidos e justificativa.
- Consequências pretendidas para dispositivos não conformes.
- Método de teste e estratégia de reversão.

## Passo a passo

1. Identifique o escopo do laboratório.
2. Registre as configurações de conformidade selecionadas.
3. Associe a política ao grupo piloto conforme sua estratégia de testes.
4. Acompanhe o estado de conformidade dos dispositivos.
5. Documente os resultados, exceções e ajustes necessários.

## Evidências

Inclua imagens dos testes, sem nomes de usuários, identificadores ou informações corporativas sensíveis.

## Validação

Documente pelo menos um dispositivo que atende às regras e um caso controlado que não atende, se aplicável ao laboratório.
