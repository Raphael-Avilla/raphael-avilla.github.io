# Projetos práticos

Aqui serão publicados projetos completos. A ideia é demonstrar **o problema, as decisões técnicas, a implementação e o resultado**, indo além de um tutorial isolado.

## Comece por aqui

- [Modelo de projeto técnico](modelo-projeto.md): página de referência para documentar seus próprios trabalhos.

Ao publicar um projeto real, deixe claro se o cenário é um **laboratório**, **projeto pessoal** ou **implantação autorizada em produção**.
